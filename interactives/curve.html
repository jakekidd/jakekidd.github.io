The solid line is a stack of diminishing-return bumps, one per breakthrough, all chasing the same ceiling: the best of what humans have written down. Add breakthroughs and it gets there faster. It doesn't cross. The dotted line is the same early data extrapolated as an exponential, which is what the slides show; the early part of a log looks exactly like the early part of an exponential. The ceiling itself can drift: if the people producing the training data get dumber, the line the curve is chasing sinks, and the curve sinks with it. The only line that crosses is a domain with an exact verifier, where the reward isn't human judgment.
